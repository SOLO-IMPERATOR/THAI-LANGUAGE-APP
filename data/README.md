# База данных тайских разговорных фраз и слов (Thai Spoken Database)

Официальная структурированная база данных для репозитория **Тайский фразовик (Thai Spoken PWA)**.

## Источник данных (runtime)

Сервер использует **SQLite**: файл `data/app.db`.

- таблица `phrases` — разговорные фразы
- таблица `words` — словарь
- таблица `users` — пользователи (стартует пустой)
- таблица `user_phrase_progress` — SRS-прогресс пользователя по фразам
- таблица `user_review_history` — история ответов (success/failure)

Миграция из JSON:

```bash
npm run migrate:sqlite
```

JSON-файлы ниже остаются как исходники для повторной миграции.

## Содержимое репозитория
- `app.db` — runtime SQLite (создаётся миграцией, обычно не коммитится)
- `thai_phrases_database.json` — исходник ~1500 разговорных фраз для миграции
- `words_dictionary.json` — исходник словаря для миграции

Расширение набора фраз:

```bash
npm run expand:phrases && npm run migrate:sqlite
```

## Структура фразы
Каждая фраза содержит:
- `id`: уникальный идентификатор (число)
- `category`: категория («Приветствия и этикет», «Кафе и еда», «Магазины и рынок», «Транспорт и такси», «Отель и жильё», «Здоровье и аптека», «Общение и экспаты», «Путешествия и отдых», «Связь и быт», «Описания и оценки»)
- `tags`: массив поисковых тегов
- `russian`: точный перевод фразы на русский язык без лишнего мусора
- `male`:
  - `thai`: форма фразы для мужчин с вежливой частицей **ครับ** (кхра́п / кхап) и мужским местоимением **ผม** (пхо̌м)
  - `transcription_ru`: русская практическая транскрипция с тонами
  - `polite_particle`: "ครับ"
- `female`:
  - `thai`: форма фразы для женщин с вежливой частицей **ค่ะ** (кха̂) для утверждений или **คะ** (кха́) для вопросов, и местоимением **ฉัน / ดิฉัน** (чха̌н / дича̌н)
  - `transcription_ru`: русская практическая транскрипция с тонами
  - `polite_particle`: "ค่ะ" или "คะ"
- `words`: пословная деконструкция фразы с тонами и значениями отдельных слов.

## Правила вежливых частиц в разговорном тайском языке
- **Мужской пол (Male):**
  - Вежливая частица: **ครับ** (`кхра́п` или `кхап`) в утверждениях и вопросах.
  - Местоимение первого лица: **ผม** (`пхо̌м` — «я»).
- **Женский пол (Female):**
  - Вежливая частица в утверждениях, ответах, согласиях: **ค่ะ** (падающий тон: `кха̂`).
  - Вежливая частица в вопросах (например, ไหมคะ, เท่าไหร่คะ, อะไรคะ): **คะ** (высокий тон: `кха́`).
  - Местоимение первого лица: **ฉัน** (`чха̌н` — «я») или **ดิฉัน** (`дича̌н` — «я, вежл.»).
